# 레트로아크 버튼·메뉴 사용법 (판도라 사가, 직접 만든 RetroArch)

## 버튼 이름 (기기에 인쇄된 글자)
```
 윗줄:  B   C   D
 아랫줄: A   E   F          그 밖: Start / Coin / 방향키
```

## 게임 중 (코인을 누른 채로 다른 버튼)
| 누를 것 | 기능 |
|---|---|
| 코인 + **Start** | **게임 끝내기** (한글 목록으로 돌아감) |
| 코인 + **B** (윗줄 왼쪽) | 레트로아크 메뉴 열기 / 닫기 |
| 코인 + **A** (아랫줄 왼쪽) | 지금 상태 저장 |
| 코인 + **E** (아랫줄 가운데) | 저장한 상태 불러오기 |
| 코인 + **F** (아랫줄 오른쪽) | 일시정지 |
| 코인 + **C** (윗줄 가운데) | 게임 처음부터 다시 (리셋) |
| 코인 + **D** (윗줄 오른쪽) | 빨리감기 켜기/끄기 |
| 코인 + **위 / 아래** | 저장 칸 번호 올리기 / 내리기 |
코인만 단독으로 누르면 게임에서는 Select 버튼이 된다.

## 레트로아크 메뉴 안에서
| 누를 것 | 기능 |
|---|---|
| 방향키 위/아래 | 항목 이동 |
| 방향키 오른쪽 / 왼쪽 | 값 바꾸기 (또는 하위 메뉴 들어가기 / 나가기) |
| **D** (윗줄 오른쪽) | 확인 (들어가기) |
| **A** (아랫줄 왼쪽) | 뒤로 |
| **E / F** (아랫줄 가운데·오른쪽) | 목록을 한 페이지씩 위/아래 |
| 코인 + B | 메뉴 닫고 게임으로 돌아가기 |

## 끝내는 방법 (3가지)
1. 게임 중: **코인 + Start**
2. 메뉴 안: 맨 아래 **"Quit RetroArch"** 에서 D
3. 시험용 스크립트(9829, 9831)는 정해진 시간(3분·40초) 뒤 **저절로 닫힌다**

## 메뉴에서 자주 보는 곳 (영어로 나옴)
- Settings → Video → Scaling : 화면 비율, 정수 배율
- Settings → Audio : 소리
- Settings → Input → Hotkeys : 단축키 확인
- Main Menu → Quit RetroArch : 끝내기
메뉴에서 바꾼 값은 "Save Current Configuration" 을 해야 남는다. (원본은 ra.cfg.bak 으로 보관되어 있다.)

## 소리와 속도 (해결됨, 2026-11-01)
- 증상: 게임이 약 24프레임으로 느리고, 소리가 아예 안 나거나 지지직거렸다.
- 원인: 새로 빌드한 RetroArch 1.22 는 소리를 부동소수점으로 보내고, ALSA 가 이를 32비트(S32)로 바꿔 RK3128 내장 코덱에 넘긴다. 이 칩은 32비트로 열면 절반 이하 속도로 소비하며 잡음이 난다(순정 1.7.4 는 16비트로 보낸다). HDMI 쪽 장치(카드 0, 장치 1)는 열리지 않는다.
- 해결: 카드의 `pandory/ra/.asoundrc` 에 16비트로 코덱에 직접 연결하는 장치 `ra16hw` 를 만들고 `ra.cfg` 에서 `audio_device = "ra16hw"` 로 지정. 시험: 59 fps, 코덱 형식 S16_LE, 소비 속도 정상.
- 주의: `.asoundrc` 는 HOME 이 `pandory/ra` 일 때만 읽힌다(스크립트와 MinosFront 가 HOME 을 그렇게 설정함). 이 경로는 순정의 볼륨 조절(softvol)을 거치지 않으므로 음량은 `ra.cfg` 의 `audio_volume`(dB, 음수=작게)으로 조절한다.
